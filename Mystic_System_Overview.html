Page 1 – High-Level Overview

Short Description

The Mystic Autonomous AI Trading Engine is a self-hosted AI crypto trading system that runs on your own infrastructure. It executes fully autonomously: from ingesting market data and generating signals to placing and managing orders, without manual intervention. The design is risk-first, with capital protection, position limits, and circuit breakers built into the pipeline before any execution. Every decision and trade is continuously logged and traceable, with structured evidence packets produced for audit and compliance.

Architecture (Data Flow)

Market Data → AI Signal Engine → Redis Signal Layer → Portfolio / Risk Engine → Exchange Execution → Ledger & Logs

Page 2 – Capabilities

Core Functions

  • Autonomous Buy/Sell Execution — Order placement and lifecycle managed by the engine.
  • AI Confidence Scoring — Signals carry confidence scores; execution respects thresholds.
  • Risk & Position Controls — Limits on size, exposure, and symbol concentration.
  • Portfolio Management — Position tracking, rebalancing, and dust handling.
  • Precision/Dust Handling — Minimum order sizes and dust rules to avoid failed orders.
  • Continuous Logging — Structured logs for signals, risk checks, and executions.
  • Evidence Packet Automation — Packets generated for audits and handoff.

Technical Stack

  • Python / FastAPI — Core services and API layer.
  • Redis — Signal layer and shared state.
  • SQLite — Persistent ledger and config.
  • Binance API — Market data and execution (exchange integration).
  • Self-Hosted Architecture — No dependency on third-party trading clouds.

Operational Traits

  • Runs without supervision in production.
  • Crash-resilient design with recovery and circuit breakers.
  • Transfer-ready documentation for handoff or due diligence.
  • Evidence packets auto-generated from logs and state.
